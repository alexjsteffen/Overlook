# Windows icon

Overlook.png was generated with the built-in image generation tool, using
Overlook/Assets.xcassets/AppIcon.appiconset/icon_512x512@1x.png as the reference.
Overlook.ico contains 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixel versions.
Overlook.rc embeds it as resource 101; build.ps1 compiles and links the resource.

Prompt: Create a Windows 11 Fluent app icon inspired by the reference Mac
Overlook icon. Single centered clean dimensional blue remote monitor behind a
blue laptop with white terminal chevron and cursor, linked by one cyan arc.
Simplify strongly for legibility at 32px. No brand words, no text, no tiny ports
or keyboard details, no extra KVM box. Rich navy and luminous cyan, restrained
soft 3D Fluent shading. Large silhouette filling 88% of square canvas,
transparent exterior background, no enclosing square tile. Production app icon.
